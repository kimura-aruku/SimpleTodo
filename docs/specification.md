# Simple Todo 仕様

## 目的

Slack Canvas や Notion のような汎用ツールではなく、Todo管理だけに集中できるシンプルなデスクトップアプリを提供する。

## 対象環境

- Windows デスクトップ
- Electron ベースのローカルアプリ

## 基本機能

- アプリ起動時に作成済みのTodoを一覧表示する。
- 左側に常時表示するサイドバーを配置し、Todoリストを切り替えられる。
- サイドバーは画面幅の約2割、Todo表示領域は約8割を使用する。
- サイドバー上にはTodoリスト名を表示する。
- Todoリスト名をクリックすると選択状態になり、そのリストに属するTodoを右側に表示する。
- 選択中のTodoリスト名を画面上部に表示する。
- 選択中のTodoリスト名は画面上部で編集できる。
- サイドバーの `+` ボタンでTodoリストを作成できる。
- 新しいTodoリストは空のTodoを1つ持つ状態で作成する。
- すべてのTodoリストは常に1つ以上のTodoを持つ。
- サイドバーの赤い `-` ボタンで選択中のTodoリストを削除できる。
- 同一画面内でTodoを追加できる。
- 画面上部の `+` ボタンで先頭にTodoを追加できる。
- 各Todo行の `+` ボタンで、そのTodoの直下に新規Todoを追加できる。
- `+` ボタンで追加したTodoに本文を入力しないままフォーカスアウトした場合、そのTodoは保存せず削除する。
- ただし、Todoリスト内のTodoが1つだけの場合は、本文が空のままフォーカスアウトしても削除しない。
- 各Todo行の赤い `-` ボタンで、そのTodoを削除できる。
- Todoが1つだけのTodoリストでは、最後のTodoを削除できない。
- Todo行のチェックボックス左にドラッグ用ハンドルを表示し、ドラッグ操作でTodoの順番を変更できる。
- Todo行の `-` ボタンと `+` ボタンの間には、押し間違いを防ぐためボタン幅の約1/3の間隔を設ける。
- Todoのチェックボックスで完了・未完了を切り替えられる。
- 完了済みTodoは打ち消し線と薄い文字色で表示する。
- 画面上部の「未完了」「完了」チェックボックスで表示対象を絞り込める。
- Todo本文が長い場合は折り返し表示し、行の高さを内容に合わせて広げる。
- Todoはローカルに保存し、次回起動時に復元する。

## 初期データ

初回起動時に保存データが存在しない場合は、操作確認用のTodoを少数作成する。
