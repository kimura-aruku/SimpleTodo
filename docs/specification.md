# Simple Todo 仕様

## 目的

Slack Canvas や Notion のような汎用ツールではなく、Todo管理だけに集中できるシンプルなデスクトップアプリを提供する。

## 対象環境

- Windows デスクトップ
- Electron ベースのローカルアプリ

## 基本機能

- 本仕様およびユーザーとのやり取りでは、画面右側に表示する個々の項目を「Todo」、画面左側に表示するTodoの集まりの個々を「Todoリスト」と呼ぶ。

- アプリ起動時に作成済みのTodoを一覧表示する。
- 左側に常時表示するサイドバーを配置し、Todoリストを切り替えられる。
- サイドバーは画面幅の約2割、Todo表示領域は約8割を使用する。
- サイドバー左上には `Lists` などの見出しを表示しない。
- サイドバー上にはTodoリスト名を表示する。
- Todoリスト名をクリックすると選択状態になり、そのリストに属するTodoを右側に表示する。
- 各Todoリストはドラッグアンドドロップで表示順を変更でき、変更後の順番を次回起動時に復元する。
- 選択中のTodoリスト名を画面上部に表示する。
- 選択中のTodoリスト名は画面上部で編集できる。
- サイドバーの `+` ボタンでTodoリストを作成できる。
- 新しいTodoリストは空のTodoを1つ持つ状態で作成する。
- すべてのTodoリストは常に1つ以上のTodoを持つ。
- サイドバーの赤い `-` ボタンで選択中のTodoリストを削除できる。
- 同一画面内でTodoを追加できる。
- 画面上部の `+` ボタンで、どのTodoの親でも子でもないTodoをリスト末尾に追加できる。
- 画面上部の `+` ボタンの下に詳細表示モードを切り替えるセレクトボックスを表示する。
- 詳細表示モードは `シンプル`、`締切`、`工数` から選択でき、初期値は `シンプル` とする。
- 詳細表示モードの選択値はTodoリストごとに保存し、リスト切り替え時と次回起動時に各リストの選択値を復元する。
- 詳細表示モードが `シンプル` の場合、Todo行には追加情報を表示しない。
- 詳細表示モードが `締切` の場合、各Todo行の削除ボタンより少し左に日付入力欄を表示する。
- 締切はドラムロール形式のネイティブ日付入力で選択でき、入力欄の初期値は空とする。日付選択UIを開いたときの基準日は今日の日付とする。
- 詳細表示モードが `工数` の場合、各Todo行の削除ボタンより少し左に工数入力欄を表示する。
- 工数入力欄は数値と小数点のみを受け付け、入力欄の初期値は空とする。
- 詳細表示モードの変更は表示のみを切り替える操作であり、入力済みの締切や工数は保持する。
- 詳細表示モードが `工数` の場合、画面上部の未完了数・完了数の右に、それぞれ未完了Todoと完了Todoの工数合計を表示する。
- 各Todoには、詳細や現状を改行を含む自由な文章で記録できる。
- Todo詳細を編集する縦三点リーダー `︙` のボタンは、`締切` モードでは締切日付の左、`工数` モードでは工数の左、`シンプル` モードでは削除ボタンの左に表示する。
- 詳細ボタンをクリックすると複数行テキストボックスを持つポップアップを表示し、ポップアップを閉じた時点で入力内容を保存する。
- 詳細を登録しているTodoへマウスカーソルを重ねると、登録内容を改行を保ったツールチップ形式で表示する。
- 各Todo行の `+` ボタンで、そのTodoの子Todoを子階層の末尾に追加できる。
- 子Todoの `+` ボタンで孫Todoを追加できる。
- 子Todoは階層が深くなるにつれてインデントして表示する。
- `+` ボタンで追加したTodoに本文を入力しないままフォーカスアウトした場合、そのTodoは保存せず削除する。
- ただし、本文が空のTodoをドラッグで移動した場合は、フォーカスアウトしても削除しない。
- ただし、Todoリスト内のTodoが1つだけの場合は、本文が空のままフォーカスアウトしても削除しない。
- 各Todo行の赤い `-` ボタンで、そのTodoを削除できる。
- Todoが1つだけのTodoリストでは、最後のTodoを削除できない。
- Todo行のチェックボックス左にドラッグ用ハンドルを表示し、ドラッグ操作でTodoの順番と親子関係を変更できる。
- ドラッグ中は、移動中Todoの元位置を領域ごと非表示にし、離したときの挿入位置にTodo名を仮行としてプレビュー表示する。
- ドラッグ中は、親・子・孫などの階層移動可能領域を示す縦の点線ガイドを表示する。
- Todo行の中央付近かつ1階層右側にドロップした場合、そのTodoの子の先頭に移動する。
- Todo行の上側または下側にドロップした場合、横位置で指定した階層の前後に移動する。
- Todo行左側のインデント領域にドロップした場合、Todoを浅い階層へ移動できる。
- 浅い階層へ移動する場合、ドラッグしたTodo自身だけが移動し、そのTodoの子は元の親へ繰り上がる。
- Todo行の `-` ボタンと `+` ボタンの間には、押し間違いを防ぐためボタン幅の約1/3の間隔を設ける。
- Todoのチェックボックスで完了・未完了を切り替えられる。
- 完了済みTodoは打ち消し線と薄い文字色で表示する。
- `Ctrl+Z` で直前のTodo操作を取り消せる。
- 取り消し対象にはTodoの追加、削除、本文変更、完了切替、ドラッグ移動、Todoリストの追加、削除、名前変更を含める。
- 画面上部の「未完了」「完了」チェックボックスで表示対象を絞り込める。
- Todo本文が長い場合は折り返し表示し、行の高さを内容に合わせて広げる。
- Todoはローカルに保存し、次回起動時に復元する。
- 起動中に発生したエラーはプロジェクト直下の `logs/last-error.log` へ最後の利用時分だけ記録し、次回起動時にクリアする。

## 初期データ

初回起動時に保存データが存在しない場合は、操作確認用のTodoを少数作成する。
