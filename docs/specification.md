# Simple Todo 仕様

## 目的

Slack Canvas や Notion のような汎用ツールではなく、Todo管理だけに集中できるシンプルなデスクトップアプリを提供する。

## 対象環境

- Windows デスクトップ
- Electron ベースのローカルアプリ

## 基本機能

- アプリ起動時に作成済みのTodoを一覧表示する。
- 同一画面内でTodoを追加できる。
- 画面上部の `+` ボタンで先頭にTodoを追加できる。
- 各Todo行の `+` ボタンで、そのTodoの直下に新規Todoを追加できる。
- Todoのチェックボックスで完了・未完了を切り替えられる。
- 完了済みTodoは打ち消し線と薄い文字色で表示する。
- 画面上部の「未完了」「完了」チェックボックスで表示対象を絞り込める。
- Todoはローカルに保存し、次回起動時に復元する。

## 初期データ

初回起動時に保存データが存在しない場合は、操作確認用のTodoを少数作成する。

## 今後の拡張候補

- Todoの削除
- 並び替え
- 期限やメモ
- 検索
- データのエクスポート・インポート
